# Cinematic intro asset

Upload the final opening movie here with this exact filename:

- `intro.mp4`

Full repository path: `src/assets/cinematics/intro.mp4`

Recommended export:
- MP4 container, H.264 video, AAC audio
- 1920×1080 (16:9); 30 or 60 fps
- Keep important text inside the central safe area for phone screens
- Aim for 30–90 seconds and optimize file size for Android

The game displays this video full-screen before the opening story on a fresh save. If the file is not present or cannot play, the game falls back to the opening story instead of getting stuck. The video can be skipped by the player.
