# User-supplied game assets

Keep supplied game assets in these folders:

- Cinematic opening video: `src/assets/cinematics/intro.mp4`
- Boss portraits: `src/assets/images/bosses/` — see that folder's README for exact filenames.
- Sound effects: `src/assets/audio/sfx/` — see that folder's README for suggested filenames.
- Music: `src/assets/audio/music/` — see that folder's README for suggested filenames.

The Android build copies `src/` into the web bundle, so files placed here become available to the game at runtime. Upload actual media files only after they are finalized; README files are placeholders and do not contain demo media.
