# Sound effects drop folder

Place supplied sound effects in this folder. Suggested filenames (we will connect them to the game after the audio files are uploaded):

- `ui-confirm.ogg` — menu/selection confirmation
- `launch.ogg` — aircraft launch
- `engine-loop.ogg` — flight engine loop
- `weapon-fire.ogg` — cannon fire
- `missile-launch.ogg` — guided missile launch
- `missile-impact.ogg` — missile impact
- `boss-warning.ogg` — boss approach warning
- `boss-hit.ogg` — boss takes damage
- `boss-defeat.ogg` — boss defeated
- `fuel-pickup.ogg` — floating fuel pickup
- `shield.ogg` — special ability
- `explosion.ogg` — explosion
- `victory-stinger.ogg` — final reveal / victory

OGG Vorbis is preferred for compact Android assets. WAV is also acceptable for short effects. Keep source filenames stable when uploading.
