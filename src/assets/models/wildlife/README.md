# الماء والبحر والطبيعة أسفل الطائرة

المسار: `src/assets/models/wildlife/`

ضع هنا نماذج أو قطعًا بيئية للماء والبحر والسواحل والجزر، بما يناسب المنطقة والطقس. أسماء مقترحة: calm_ocean_tile.glb و stormy_water_tile.glb و tropical_coast.glb. للماء الممتد غالبًا يكون سطح منخفض المضلعات أو خامة متحركة أفضل أداءً من مجسم بحر ضخم.

## قواعد الإضافة
- ضع ملفات `.glb` داخل هذا المجلد مباشرة أو في مجلدات فرعية حسب المنطقة/النوع.
- استخدم أسماء ملفات إنجليزية قصيرة وواضحة، وتجنب المسافات والأحرف الخاصة.
- ضمّن الخامات داخل ملف GLB قدر الإمكان، وافحص حجم الملف قبل إضافته.
- أضف اسم النموذج ومصدره وترخيصه عند استيراد نموذج خارجي.
- **مهم:** تجهيز المجلد لا يعني أن النموذج سيظهر تلقائيًا داخل اللعب؛ يلزم ربطه بنظام التحميل والظهور والسلوك المناسب.
